# Battle Tetris

## 프로젝트 개요

한 화면에서 두 명이 동시에 플레이하는 로컬 대전형 테트리스 게임.
React로 구현하며 단일 페이지로 구성한다.

## 기술 스택

- React (상태관리는 React hooks만 사용)
- CSS Modules 또는 Tailwind CSS

## 화면 구성

- 좌측: Player 1 게임 보드 (10x20)
- 우측: Player 2 게임 보드 (10x20)
- 각 보드 옆에 다음 블록 미리보기 (3개), 점수, 레벨, Hold 피스 표시

## 조작키

시작 화면의 Controls 옵션에서 키를 변경할 수 있다.

| 동작        | Player 1 | Player 2 |
| ----------- | -------- | -------- |
| 좌이동      | A        | ←        |
| 우이동      | D        | →        |
| 회전        | W        | ↑        |
| 소프트 드롭 | S        | ↓        |
| 하드 드롭   | Space    | Enter    |
| 홀드        | Q        | R        |
| 일시정지    | ESC      | ESC      |

싱글 모드 기본값은 방향키 이동, ↑ 또는 Z 회전, Ctrl 또는 X 반시계 회전, Space 하드 드롭, Shift 또는 C 홀드다.

## 핵심 기능

### 블록 시스템

- 7가지 테트로미노 (I, O, T, S, Z, J, L)
- 7-bag 랜덤화: 7개 블록을 한 세트(bag)로 묶어 랜덤 셔플 후 순서대로 사용, 소진되면 새 bag 생성
- 다음 블록 3개 미리보기
- Hold 피스: 현재 블록을 홀드하고 이후에 꺼내어 사용 가능 (한 블록당 1회 제한)
- 스폰 위치: 블록은 항상 보드 상단 중앙에서 생성, 생성 위치에 블록이 이미 있으면 즉시 게임오버

### 조작 시스템

- DAS (Delayed Auto Shift): 이동키 꾹 누를 때 167ms 딜레이 후 연속 이동 시작
- ARR (Auto Repeat Rate): DAS 이후 블록 반복 이동 속도 33ms

### 회전 시스템

- SRS (Super Rotation System): 표준 Wall Kick 회전 보정 규칙 적용
- T-Spin 감지: T블록 회전으로 라인 클리어 시 점수 2배
- T-Spin Mini: T-Spin 조건 일부 충족 시 점수 0.5배 (일반 T-Spin과 구분)

### 물리 시스템

- Lock Delay: 블록이 바닥에 닿은 후 0.5초간 이동 및 회전 가능
- Lock Delay 리셋 제한: 이동/회전으로 리셋 가능하나 최대 15회 제한 (무한 버티기 방지)
- 고스트 피스: 블록이 떨어질 위치를 바닥에 투명하게 표시

### 점수 시스템

- 라인 클리어 점수: 1줄=100, 2줄=300, 3줄=500, 4줄(테트리스)=800
- T-Spin 클리어 시 점수 2배, T-Spin Mini 클리어 시 점수 0.5배
- Back-to-Back: 테트리스 또는 T-Spin 연속 달성 시 점수 1.5배
- 콤보: 연속 라인 클리어마다 콤보 수 x 50 보너스 점수
- 퍼펙트 클리어: 보드를 완전히 비우면 대량 점수 + 상대방에게 10줄 방해
- 레벨업마다 낙하 속도 증가

### 대전 시스템

- 2줄 이상 클리어 시 상대방에게 방해줄 추가 (클리어 줄 수 - 1)
- 방해줄은 랜덤 위치에 구멍 1개 포함
- 가비지 캔슬: 상대방 방해줄이 오는 중에 라인 클리어하면 방해줄 상쇄 가능
- 위험 경고: 블록이 일정 높이 이상 쌓이면 화면 테두리 빨간색 경고
- 한 명의 블록이 천장에 닿으면 상대방 승리

### 기타

- 게임 시작 전 3, 2, 1, GO! 카운트다운
- ESC 일시정지
- 재시작 버튼
